What it does

⏺

Auto record on arm

Recording starts the instant the FC arms and stops on disarm, with an optional delay — no button to forget mid-flight.

◱

Live OSD telemetry

Battery %, recording state and time, mode, resolution/FPS, stabilisation, and SD space remaining — pushed straight into Betaflight's OSD as fully customizable templates.

⌁

Browser flash & config

No PlatformIO required to get running. Flash a release build and manage every setting from a web page over WebSerial.

✎

Remembers your cameras

Up to 64 previously-paired cameras saved on-device. Fall back to the last one, pin a specific unit, or connect to whichever has the strongest signal.

⇄

AUX-switch mode control

Map an AUX channel to slow-motion, hyperlapse, or a preset toggle — and Burst Slo-Mo mid-recording on supported GoPros.

⚑

BF 4.5 and 4.6+

Uses Custom Message OSD fields on 4.6+, or falls back to Pilot Name / Craft Name on 4.5 where those fields don't exist yet.

Supported cameras

DJI Action Default

Action 4/5 Pro, Action 6, Osmo 360, and compatible bodies over DJI's own BLE protocol. 2 Hz status push.

GoPro HERO9+

Open GoPro BLE API, plus legacy HERO4/5 Session support with automatic protocol fallback.

Caddx Orca

Wi-Fi/HTTP control over the camera's own access point — no BLE pairing flow needed.

Sony Alpha

BLE remote-button protocol. Record start/stop and battery; open Bluetooth Rmt Ctrl to pair.

Blackmagic

Pocket Cinema, URSA, and Studio range over the official Camera Control Protocol via BLE.

Insta360

X3, X4, ONE R/RS, GO 2/3, and similar bodies over the same BLE channel the official app uses.
